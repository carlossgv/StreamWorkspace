# Shell Commands

- When invoking `rm`, `cp`, or `grep`, prefix the command name with a backslash to bypass shell aliases: use `\rm`, `\cp`, and `\grep`.

# Git

- When creating commits, use Conventional Commit messages, for example `feat: add endpoint selector` or `fix: skip prefilled MINSAL identity fields`.

# Code Style

- Use code comments only when they are genuinely needed to explain context that is not clear from the code itself.
